    Tree view

    Smaller IDs go left, larger go right

    Insert

    Start at the root. Go left if the new ID is smaller, right if larger, and attach it at the first empty spot. Duplicate IDs are rejected.

    O(h)

    Search

    Compare the ID with each node and move left or right until it matches or the path ends.

    O(h)

    Delete

    A leaf is removed. A node with one child is replaced by that child. With two children, copy the inorder successor, then delete it.

    O(h)

    Display

    Visit left subtree, then the node, then the right subtree. The output is sorted by contact ID.
