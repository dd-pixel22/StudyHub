Understanding a Node

DATA

Stores the student's registration number, name and marks.

NEXT POINTER

Stores a reference to the next node in the list.

HEAD

NULL

LEARNING CORNER

Data Structures Guide

Understand the concepts behind StudentHub.

01

What is a Data Structure?

A data structure is a way of organizing and storing data so it can be accessed and modified efficiently.

02

Singly Linked List

A linear data structure made of nodes. Each node contains data and a pointer to the next node.

03

Insertion

Insertion adds a new node to the linked list. It can happen at the beginning, end or a specified position.

04

Deletion

Deletion removes a node and updates the necessary links so the remaining nodes stay connected.

05

Traversal

Traversal visits each node sequentially, starting from the head pointer until NULL is reached.

06

Searching

Searching checks each node until the required registration number is found or the list ends.
